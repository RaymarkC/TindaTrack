# TindaTrack

A simple mobile inventory and sales tracker for small sari-sari stores, built with Flutter and Firebase.

**Team:** Raymark Jan B. Corbita (Lead Developer) and Jann Florence Abad
**Course:** Mobile Development, UIC CCS (2026–2027)

## About
Many sari-sari store owners still track stock in notebooks or by memory. TindaTrack gives them an easy way to see what is in stock, what is running low, and what was sold, with big buttons and plain words.

## Features
- **Welcome screen:** enter your name and store name, or tap a saved user to continue
- **Separate records per user:** each user has their own items, history and reports
- **Home dashboard:** total items, low-stock items and today's sales
- **Inventory:** search items and filter by All, Low or In stock
- **Item details:** Stock In and Sold buttons, dates and recent history
- **Quick add:** tap common sari-sari items to fill in the name and price
- **Reports:** sales, pieces sold, stock in and best sellers for today, 7 days, 30 days or all time
- **Settings:** change user, store name and the low-stock limit
- **Cloud database:** data is saved in Firebase Firestore and works offline

## Tech Stack
- Flutter (Dart), Material 3
- Firebase Core and Cloud Firestore
- shared_preferences (saves settings on the device)

## How to Run
1. Install [Flutter](https://docs.flutter.dev/get-started/install)
2. Clone this repository:
   ```
   git clone https://github.com/ORG-NAME/TindaTrack-Corbita-Abad.git
   cd TindaTrack-Corbita-Abad
   ```
3. Get the packages:
   ```
   flutter pub get
   ```
4. Run the app:
   ```
   flutter run -d chrome
   ```
   (or choose an Android device or emulator)

## Project Structure
```
lib/
  main.dart              # all screens and app logic
  firebase_options.dart  # Firebase settings (generated by FlutterFire)
```

## Database Structure (Firestore)
```
users/{user}
  items/{item}   -> name, qty, price, added, updated
  logs/{log}     -> history of new items, stock in, sold and removed
```
